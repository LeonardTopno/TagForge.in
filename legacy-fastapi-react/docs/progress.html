Application overview Technical overview

Application flow

A shop signs in, creates a hang tag, checks the millimetre preview, then prints one page through the TVS LP 46 NEO browser-print workflow and folds at the centre mark. Creating a tag spends 1 credit unless an unlimited plan is active. Print and reprint do not spend credits.

Shop session Tag and print Credits Admin portal
1

Register or sign in

A shop owner creates an account (free starter credits) or signs in. The session is a JWT scoped to that shop. Platform staff open /admin-portal instead.

2

Enter the piece and preview

Staff pick an item from the shop catalogue, choose Gold or Silver, and enter gross and stone weights. Net weight is calculated. Actual Preview shows one printable face: weights left, fold mark centre, category + item and barcode right, at the shop’s millimetre size.

3

Save, charge, print

Saving stores the tag and spends 1 credit, unless unlimited printing is active. Print opens the browser print dialog (not direct USB). Choose TVS LP 46 NEO — one page, then fold at the centre mark. Calibrate millimetre size and offsets in Tag Settings.

4

History, billing, settings

History searches by tag number or item name and reprints without re-entry. Billing activates Starter, Growth, or Pro locally until Razorpay is wired. Settings cover shop profile (including logo), millimetre layout, and the item catalogue.

TVS LP 46 NEO browser-print workflow

Built for the TVS LP 46 NEO label printer. On-screen millimetre preview and browser print dialog — select that printer when prompted; no direct USB from the web app. Tag width, height, font, and offsets are tuned in Settings → Tag Settings and calibrated on the physical printer.

Single-side hang-tag layout

One printable face: left panel Grs.Wt / Stn.Wt / Nt.Wt, centre fold mark, right panel category + item, Code 128 barcode, tag number. Barbell neck and tail are structural only. One browser print page; fold after printing. Tag Settings shows TVS LP 46 NEO and paper type.

Done

Shop item catalogue

Each shop maintains named items (seeded defaults such as Ring, Chain, Mangalsutra). Create Tag uses that list as a dropdown. Catalogue CRUD lives under Settings → Items.

Done

Shop logo

Owners upload a JPG, PNG, WEBP, or GIF (max 5 MB) in Settings → Shop. The file is stored under backend/uploads/logos/ and shown in the sidebar. It is not printed on the hang tag. Replace and remove are supported.
