Technical overview

Architecture, data model, API surface, configuration, and how credits and printing are implemented in this repository.

Application overview README

Stack

Backend

FastAPI 0.115, SQLAlchemy 2 async, Pydantic Settings, Uvicorn. Passlib/bcrypt for passwords, python-jose JWT for sessions.

Frontend

React 19, Vite 6, TypeScript. Single-page UI in frontend/src/App.tsx. Icons from lucide-react. Auth token in localStorage.

Data and runtimes

SQLite via aiosqlite for local runs. PostgreSQL 16 + asyncpg under Docker Compose. Tables created on startup.

Tenancy and auth

  • A Shop is the tenant. Users belong to one shop via shop_id.
  • Roles: owner, operator, admin. Admin routes call require_admin().
  • Register creates shop + owner, hashes the password, and writes a credit ledger grant.
  • Login and /me return a JWT plus nested user and shop payloads.
  • Tag list, create, print, settings, dashboard, and billing queries always filter by current_user.shop_id.

Data model

TableRole
shopsTenant identity, tag numbering, millimetre print layout, credit balance, expiry, unlimited-until
usersEmail, password hash, role, shop foreign key
jewellery_tagsItem, purity, weights, copies, print_count; unique (shop_id, tag_number)
print_logsWho printed which tag, copies, timestamp
billing_plansSeeded Starter / Growth / Pro plans
plan_purchasesPending/paid purchases; placeholder Razorpay ids for local testing
credit_ledger_entriesCredit/debit history with balance_after

Net weight is gross − stone − other_deduction, quantized to 3 decimals. Negative net weight is rejected with HTTP 422.

Insufficient credits return HTTP 402. Duplicate email returns 409. Admin without role admin returns 403.

Credits algorithm

  • charge_tag_credits no-ops when copies ≤ 0 or unlimited_until is still in the future.
  • Expired credits_expire_at zeros the shop balance before charging.
  • Create tag always charges copies. Print charges again only when print_count > 0 (reprint).
  • Paid credit plans add credits and extend expiry; unlimited plans extend unlimited_until.
  • Tag price and signup grant come from settings: TAG_PRICE_INR, FREE_REGISTRATION_CREDITS.

Frontend behaviour

  • Shop UI views: create, history, billing, settings.
  • Path /admin-portal swaps in the admin shell (same SPA, no router library).
  • Preview sizes the label from shop millimetre fields; print uses CSS @media print.
  • frontend/src/api.ts wraps fetch; VITE_API_BASE_URL overrides the API host.

Local run

Without Docker: venv + uvicorn app.main:app --reload in backend/, and npm run dev in frontend/. With Docker: docker compose up --build starts Postgres 16, API on 8000, Vite on 5173. SQLite schema migrations for extra shop columns are applied in create_database() for local files only.

Known gaps

  • Razorpay Orders/payments are stubbed with local order/payment ids.
  • No barcode generation (by product requirement for this milestone).
  • No Windows USB print agent yet.
  • Operator role exists on the model but registration only creates owners.
