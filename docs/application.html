TagForge

Print tags. Run your shop.

Multi-tenant jewellery hang tags for shops — create weight tags, preview at millimetre size, and print through the browser on a TVS LP 46 NEO label printer.

Technical overview Status and plans README

Each shop registers its own account. Tags, print history, layout settings, and credits stay isolated to that shop. The hang-tag preview prints weights and barcode on one face, with a centre fold mark — fold the tag so the sticker backs meet.

Who it is for

Shop owners

Register the shop, upload a logo, buy credits or an unlimited plan, and keep print layout calibrated for the counter printer.

Counter staff

Enter item details, check net weight, preview the label, then print or reprint from history.

Platform admin

Use the admin portal to review tenants, adjust credits, and edit billing plans.

What a shop can do

1

Register or sign in

Create a shop with an owner email. New shops receive free tag credits so they can try printing immediately.

2

Create a jewellery tag

Pick an item from the shop catalogue, choose Gold or Silver, and enter gross and stone weight. Net weight is calculated automatically (gross − stone). Each shop gets sequential tag numbers with a custom prefix. Creating a tag spends 1 credit.

3

Preview and print

Actual Preview shows one printable face at millimetre size: left panel Grs.Wt / Stn.Wt / Nt.Wt, centre fold mark, right panel category + item, Code 128 barcode, and tag number. Save, Save & Print, or Test Print opens the browser print dialog (not direct USB). Choose TVS LP 46 NEO as the printer — one page. Fold on the centre mark after printing. Print and reprint do not spend credits.

4

Search history

Find saved tags by tag number or item name and reprint without re-entering weights.

5

Tune shop, tag, and items

Settings has three sections: shop profile (name, address, phone, GST, logo), Tag Settings (printer and tag paper summary, prefix, millimetre width/height, font, offsets), and the item catalogue. Tag Settings shows the TVS LP 46 NEO target and fold-at-centre instructions. The logo appears in the shop sidebar, not on the printed hang tag.

Tag layout — single side, fold at centre

Left panel

Grs.Wt, Stn.Wt, and Nt.Wt on the left half of the printable face.

Centre fold

Dashed fold mark in the preview. After printing, fold here so the sticker backs on each half meet.

Right panel

Category + item name (e.g. GOLD RING), Code 128 barcode of the tag number, then the tag number.

The barbell neck and tail (to the right of the white face) are structural only — not printed. Printing is one browser page via the TVS LP 46 NEO dialog.

Printer and tag media

The counter setup targets a TVS Electronics LP 46 NEO desktop label printer loaded with jewellery barbell tags (rat-tail / dumbbell style). Shops calibrate layout in Settings → Tag Settings until the on-screen preview matches the physical label.

Tag paper — jewellery barbell roll

Material

White glossy synthetic (polyester / polypropylene). Printed with a thermal transfer ribbon, not direct thermal.

Roll format

Two-up — two tags side by side on the liner. Gap or black mark between labels for the printer sensor.

Shape

Printable face, narrow neck/bridge, and smaller adhesive tail. The tail wraps around the jewellery; the neck stays clear of the item.

Calibration workflow

1

Set Tag Settings

Enter 80 × 18 mm, font size, and zero offsets as a starting point. Confirm printer shows TVS LP 46 NEO.

2

Test print

Create a test tag and print one page. Check weights sit in the left panel and barcode in the right panel inside the white face.

3

Fold and scan

Fold on the centre mark so sticker backs meet. Scan the Code 128 barcode with a handheld scanner or phone.

4

Fine-tune offsets

Adjust X/Y offset and font in Tag Settings until preview and folded physical tag match.

TVS LP 46 NEO browser-print workflow

This application is built for the TVS LP 46 NEO label printer. Printing goes through the browser print dialog — the hosted app does not send jobs directly to USB. When the dialog opens, choose TVS LP 46 NEO as the printer. One page prints the full face: weights left, fold mark centre, item and barcode right. Fold the tag on the centre line after printing.

Tag size and offsets are configured in Settings → Tag Settings in millimetres. The Tag Settings screen also lists the target printer, tag paper type (single-side print, fold at centre), and calibration help text.

Devices and browsers

The shop UI is responsive across phone, tablet, and desktop. On narrow screens the sidebar becomes a slide-out menu; forms and billing cards stack vertically; wide tables scroll horizontally. Controls use touch-friendly sizing. Printing still goes through the browser on each device — use Chrome, Edge, Firefox, or Safari on the counter PC or tablet where the TVS LP 46 NEO is installed.
