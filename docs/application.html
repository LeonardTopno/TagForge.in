TVS LP 46 NEO browser-print workflow

Jewellery Tag Printer

A multi-tenant web app for jewellery shops to create weight tags, preview front and back hang-tag faces at real millimetre sizes, and print through the browser on a TVS LP 46 NEO label printer.

Technical overview Status and plans README

Each shop registers its own account. Tags, print history, layout settings, and credits stay isolated to that shop. The hang-tag preview prints a front (weights) and a back (item name, Code 128 barcode, tag number).

Who it is for

Shop owners

Register the shop, upload a logo, buy credits or an unlimited plan, and keep print layout calibrated for the counter printer.

Counter staff

Enter item details, check net weight, preview the label, then print or reprint from history.

Platform admin

Use the admin portal to review tenants, adjust credits, and edit billing plans.

What a shop can do

1

Register or sign in

Create a shop with an owner email. New shops receive free tag credits so they can try printing immediately.

2

Create a jewellery tag

Pick an item from the shop catalogue, choose Gold or Silver, and enter purity plus gross, stone, and other deduction. Net weight is calculated automatically. Each shop gets sequential tag numbers with a custom prefix. Creating a tag spends 1 credit.

3

Preview and print

Actual Preview shows both hang-tag faces at millimetre size. Front: Grs.Wt / Stn.Wt / Nt.Wt. Back: item name, Code 128 barcode of the tag number, and the tag number. Save, Save & Print, or Test Print opens the browser print dialog (not direct USB). Choose TVS LP 46 NEO as the printer. The dialog sends front then back as two pages. Print and reprint do not spend credits.

4

Search history

Find saved tags by tag number or item name and reprint without re-entering weights.

5

Tune shop, tag, and items

Settings has three sections: shop profile (name, address, phone, GST, logo), Tag Settings (prefix, tag width and height in millimetres, font, horizontal and vertical offsets), and the item catalogue used on Create Tag. Use Tag Settings to calibrate the layout on a TVS LP 46 NEO. The logo appears in the shop sidebar, not on the printed hang tag.

Hang-tag faces

Front

Weights on the main body: gross, stone, and net. The hanging tab is empty so the fold stays clear.

Back

Item name (uppercase), Code 128 barcode of the tag number, then the tag number. Same hang-tag outline as the front.

Print

Two pages in one browser print job. In the print dialog, select TVS LP 46 NEO. Flip the label in the printer between faces until a dual-sided path is proven.

Printer and tag media

The counter setup targets a TVS Electronics LP 46 NEO desktop label printer loaded with jewellery barbell tags (rat-tail / dumbbell style). Shops calibrate layout in Settings → Tag Settings until the on-screen preview matches the physical label.

Tag paper — jewellery barbell roll

Material

White glossy synthetic (polyester / polypropylene). Printed with a thermal transfer ribbon, not direct thermal.

Roll format

Two-up — two tags side by side on the liner. Gap or black mark between labels for the printer sensor.

Shape

Printable face, narrow neck/bridge, and smaller adhesive tail. The tail wraps around the jewellery; the neck stays clear of the item.

Suggested starting values in Tag Settings: width 80 mm, height 15 mm (app default height is 13 mm — raise to 15 mm to match measured tags), font 7–8 pt. Adjust horizontal and vertical offsets after a test print.

Calibration workflow

1

Set Tag Settings

Enter 80 × 15 mm, font size, and zero offsets as a starting point.

2

Test Print front

Create a test tag and print page 1. Check that Grs.Wt / Stn.Wt / Nt.Wt sit inside the white face.

3

Print back and scan

Flip the tag, print page 2, and scan the Code 128 barcode with a handheld scanner or phone.

4

Fine-tune offsets

Adjust X/Y offset and font in Tag Settings until both faces align. Repeat until preview and physical tag match.

TVS LP 46 NEO browser-print workflow

This application is built for the TVS LP 46 NEO label printer. Printing goes through the browser print dialog — the hosted app does not send jobs directly to USB. When the dialog opens, choose TVS LP 46 NEO as the printer. Page 1 is the front (weights); page 2 is the back (item, barcode, tag number).

Tag size and offsets are configured in Settings → Tag Settings in millimetres: width, height, font size, and horizontal and vertical offsets. Shops test-print on the TVS LP 46 NEO and adjust those values until the physical label matches the on-screen preview. After calibration is proven, a Windows print agent could be added later for unattended USB printing.

Devices and browsers

The shop UI is responsive across phone, tablet, and desktop. On narrow screens the sidebar becomes a slide-out menu; forms and billing cards stack vertically; wide tables scroll horizontally. Controls use touch-friendly sizing. Printing still goes through the browser on each device — use Chrome, Edge, Firefox, or Safari on the counter PC or tablet where the TVS LP 46 NEO is installed.
