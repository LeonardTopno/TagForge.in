Product overview

Jewellery Tag Printer

A multi-tenant web app for jewellery shops to create weight tags, preview them at real millimetre sizes, and print through the browser on a TVS LP 46 NEO label printer.

Technical overview README

Each shop registers its own account. Tags, print history, layout settings, and credits stay isolated to that shop. This version does not print barcodes.

Who it is for

Shop owners

Register the shop, buy credits or an unlimited plan, and keep print layout calibrated for the counter printer.

Counter staff

Enter item details, check net weight, preview the label, then print or reprint from history.

Platform admin

Use the admin portal to review tenants, adjust credits, and edit billing plans.

What a shop can do

1

Register or sign in

Create a shop with an owner email. New shops receive free tag credits so they can try printing immediately.

2

Create a jewellery tag

Enter item name, category, purity, pieces, gross weight, stone weight, other deduction, and copy count. Net weight is calculated automatically. Each shop gets sequential tag numbers with a custom prefix.

3

Preview and print

The on-screen preview uses millimetre CSS so the layout matches the physical label. Printing uses the browser print dialog. First print is billed as copies; later reprints spend credits again unless unlimited printing is active.

4

Search history

Find saved tags by tag number or item name and reprint without re-entering weights.

5

Tune the printer layout

Settings store tag width, height, font size, horizontal and vertical offsets, shop name on the label, and tag prefix. Shops can calibrate against the TVS LP 46 NEO without a code change.

Billing for shops

Printing is sold as tag credits. The displayed price per tag defaults to ₹2. Credits expire with the paid plan window. An unlimited plan skips per-tag debit while it is active.

Admin portal

Open /admin-portal to list shops, inspect credit ledgers, grant or reduce credits, set validity, and edit plan prices and allowances.

Why printing is in the browser

A hosted website cannot talk directly to a USB label printer in the shop. Version 1 therefore uses the browser print dialog and millimetre CSS. After physical sizes and offsets are proven, a Windows print agent can be added for unattended USB printing.
