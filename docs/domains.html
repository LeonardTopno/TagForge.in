TagForge

Print tags. Run your shop.

Suggested production hosts for the shared-hosting PHP app. Point every hostname at the same document root (this project). Host-based routing in .htaccess and includes/hosts.php selects the surface.

PurposeURLServes
Shop apphttps://tagforge.inindex.php
Mobile app / PWA entryhttps://app.tagforge.inapp.php (shop SPA, mobile surface)
Admin portalhttps://admin.tagforge.inadmin.php
APIhttps://api.tagforge.inapi.php (CORS + shared session cookie)

DNS

tagforge.in          A / ALIAS   → hosting IP
www.tagforge.in      CNAME      → tagforge.in
app.tagforge.in      CNAME/A    → same host
admin.tagforge.in    CNAME/A    → same host
api.tagforge.in      CNAME/A    → same host

Issue SSL for the apex and all subdomains (AutoSSL / Let’s Encrypt wildcard or multi-domain cert).

cPanel / Plesk

  1. Upload this project to public_html (or the app’s docroot).
  2. Add addon / subdomain aliases for app, admin, and api pointing at that same folder.
  3. Copy includes/config.example.php → includes/config.php and set MySQL + Razorpay secrets.
  4. Keep the production hosts / urls / cookie_domain values from the example.
  5. Open https://tagforge.in/install.php once, then delete install.php.

Config keys

'urls' => [
  'shop'  => 'https://tagforge.in',
  'admin' => 'https://admin.tagforge.in',
  'app'   => 'https://app.tagforge.in',
  'api'   => 'https://api.tagforge.in',
],
'hosts' => [
  'shop'  => ['tagforge.in', 'www.tagforge.in'],
  'admin' => ['admin.tagforge.in'],
  'app'   => ['app.tagforge.in'],
  'api'   => ['api.tagforge.in'],
],
'cookie_domain' => '.tagforge.in',

Behaviour

  • Shop and mobile UIs call https://api.tagforge.in/api.php when urls.api is set.
  • CORS allows the shop / app / admin origins with credentials.
  • Session cookie is scoped to .tagforge.in so login works across those hosts.
  • Password-reset links always open on the shop URL.
  • Localhost keeps empty hosts so no production redirects fire.
